Bakabakaband Score Server

馬鹿馬鹿蛮怒からのスコア登録 (JSON) を受け付け、ランキングを表示します。

エンドポイント

GET /leaderboard

ランキング (HTML)

GET /scores

ランキング (JSON)。?limit= と ?offset= でページング。

GET /scores/:id

1 件の詳細 (送信されたデータ全体を含む)

POST /submit

スコア登録。Content-Type: application/json で schema/ScoreSubmission.schema.json に従うデータを送る。

curl -X POST http://localhost:3000/submit -H "Content-Type: application/json" -d @submission.json

DELETE /scores/:id, POST /scores/:id/verify

管理操作。Authorization: Bearer <ADMIN_TOKEN> が必要。
