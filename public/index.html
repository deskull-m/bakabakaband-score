Bakabakaband Score Server

馬鹿馬鹿蛮怒からのスコア登録 (JSON) を受け付け、ランキングを表示します。

エンドポイント

GET /leaderboard

ランキング (HTML)

GET /scores

ランキング (JSON)。?limit= と ?offset= でページング。

GET /scores/:id

1 件の詳細 (送信されたデータ全体を含む)

POST /submit

スコア登録。Content-Type: application/json で schema/ScoreSubmission.schema.json に従うデータを送る。

curl -X POST http://localhost:3000/submit -H "Content-Type: application/json" -d @submission.json

DELETE /scores/:id, POST /scores/:id/verify

管理操作。Authorization: Bearer <ADMIN_TOKEN> が必要。

掲載される情報と削除依頼

掲載される情報

ゲームから送信された内容はすべて公開され、誰でも閲覧できます。具体的には次のものです。

  • キャラクター名、種族、職業、性別、性格、レベル、経験値、能力値、所持金、到達階、ターン数、プレイ時間
  • 死因、遺言 (last words)、生い立ちの履歴
  • キャラクターダンプとスクリーンショット (送信時に添付された場合)
  • ゲームのバージョンとプラットフォーム

キャラクター名・遺言・履歴は自由入力です。本名や連絡先など、公開したくない情報を入れないでください。

保存されない情報

送信元の IP アドレスは記録に保存しません。連打防止のために短時間メモリ上で数えるだけで、記録とは紐付けません。 アカウント登録やログインは不要で、メールアドレスなどの個人情報も収集しません。

保持期間

記録は削除依頼があるまで保持します。明らかに不正な記録や、他の利用者に不快な内容を含む記録は、運営者の判断で削除することがあります。

削除依頼

自分が送信した記録を消したい場合は、記録の ID (詳細画面の URL 末尾) を添えて リポジトリの Issue から連絡してください。 本人確認の手段が無いため、送信時刻や内容について確認させてもらうことがあります。
